# Virtual Casino

Standalone HTML / CSS / JS demo casino. Virtual credits only — no real money.

## Run it

1. Download `index.html`, `style.css`, and `script.js` into the **same folder**.
2. Open `index.html` in any browser.

No install. No build.

Direct files:
- [index.html](./index.html)
- [style.css](./style.css)
- [script.js](./script.js)

Or download the whole repo as a ZIP from GitHub: **Code → Download ZIP**.
